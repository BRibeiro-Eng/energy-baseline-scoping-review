# Corpus B ⊂ Corpus A — decisão de 2026-09-17

**Decisor:** revisor (Bernardo Ribeiro). **Estado:** aplicada.

## O problema
`output/corpus_profile.rosters()` calculava A e B de forma independente. Dois relatórios ficaram
em B sem estarem em A, porque o formulário Tier-1 cego (`production/reviewer_workspace/reviews/membership/blind/`)
aceitou o par incoerente `level_3b = true` + `methodological_eligibility = false`, ambos adjudicados pelo revisor:

| key | artigo | elegibilidade metodológica | level_3b |
|---|---|---|---|
| `rayyan-472535628` | Pelser, Vosloo, Mathews (2017), cimento, África do Sul | **false** (adjudicado) | true (adjudicado) |
| `rayyan-472535750` | Wu et al. (2014), vidro / centro de distribuição | **false** (adjudicado) | true (adjudicado) |

Por desenho (protocolo §5.3) B é uma partição de cartografia dentro de A: `level_3b` não tem
significado para um relatório que falhou a elegibilidade.

## A decisão
Mantém-se o veredicto de elegibilidade — tomado às cegas, antes de qualquer extração Stage C — e
aplica-se a regra B ⊂ A. **Os dois saem de B.** A elegibilidade não foi reaberta: fazê-lo depois
de ver o que cada registo contribui para a síntese seria decidir a pertença pelo conteúdo.

| | antes | depois |
|---|---|---|
| Corpus A | 331 | 331 |
| Exclusões por elegibilidade metodológica | 117 | 117 |
| Corpus B | 42 | **40** |
| Cartografados no Stage C | 41 | **39** (+1 em quarentena, `rayyan-472536714`) |
| Vista bibliométrica A∪B | 333 | deixa de existir (= A) |
