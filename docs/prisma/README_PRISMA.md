## The three statements that cannot be missing

1. **Single reviewer** (B. Ribeiro) in screening and extraction. Declared as a limitation, without softening.
2. **AI-assisted extraction** — checklist item 10. An instrument of the single reviewer, never a second reviewer; frozen form; every value with a quotation and a page; all quotations checked mechanically against the page (3 101 exact out of 3 111); **no independent human re-reading**. Said like this, it is defensible; omitted, it is not.
3. **Snowballing not executed** — `SNOWBALLING_NOT_PERFORMED_2026-09-16.md`. S = 0 by omission, not by yield. The check performed shows that the supplementation trigger would have fired, and the limitations paragraph is already written.
