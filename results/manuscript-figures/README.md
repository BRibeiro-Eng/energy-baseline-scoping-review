# Manuscript figures

TikZ sources of the figures of the article, as compiled with the MDPI LaTeX template (`\input{figures/style}` loads the palette and TikZ libraries). Values are those of the article's tables and of `data/06-late-verification/`; nothing here is computed.

| File | Figure |
|---|---|
| `fig-chain.tex` | Normative measurement chain (ISO 50001 → ISO 50006 → ISO 50015, M&V) |
| `fig-prisma.tex` | PRISMA-ScR flow |
| `fig-conditions.tex` | Corpus B: reporting of boundary, re-estimation, validity domain and out-of-sample results |
| `fig-mechanisms.tex` | Corpus B: mechanisms named, by cause and effect |
| `fig-refinery-map.tex` | Evidence map of the 13 refinery and petrochemical reports |
